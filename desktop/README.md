## 🪟 Сборка Windows-версии

Приложение собрано в один portable `.exe` со встроенным браузером (Edge WebView2) — Python, .NET и браузеры на целевой машине не нужны.

Готовый файл: [Releases](https://github.com/magga-worker/CompetitorAI/releases) (`CompetitorAI.exe`). В git бинарник не хранится.

При первом запуске выходит форма «Введите API ключ» / «Сохранить ключ»; ключ хранится в файле конфигурации в зашифрованном виде.
Настройки позволяют сменить модель и OpenAI-совместимого провайдера. Баланс счёта отображается только для AITUNNEL.

Парсинг сайтов и UI идут через встроенный WebView2, а не через Playwright Chromium из каталога `.browsers`.
